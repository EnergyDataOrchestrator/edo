## Business Context
> **As a** Researcher / UI user
> **I want to** see only real, synced data in the UI and get a helpful explanation when there is none
> **So that** I never mistake test data for a real project — "randomly the Weatherstation Q3-2026 appears" must become impossible

The Weatherstation Q3-2026 ("Measurement_02" / the CF2-003 testbed example) kept surfacing in the UI through two independent paths: **demo fallbacks** in the frontend (a `DEMO_PROJECT` injected into an empty project list, a bundled sample crate in `TheEditor`, a demo message in `TheDatabus`, a static debug view in `TheTransform`) and **leftover replay graphs** in the Fuseki `/projects` dataset (`urn:edo:trip:replay`, `urn:edo:agnostic-trip:replay` — written by the fuseki-proto verify stages and never dropped). This card removes both paths and defines the behaviour for the **"no projects in RDMO"** situation.

---

## Plan
1. **Fuseki hygiene (root cause of store pollution):** after the verify stage of `trip run` / `agnostic-trip run` writes its report, `DROP SILENT` the replay named graph so the prototype tools no longer leave state behind in the `/projects` dataset.
2. **Frontend policy — no demo data:** delete the bundled demo assets (`ro-crate-weatherstation.json`, `internal-format-example.json`); `TheProjectDrawer` shows a disabled "No projects" item with a reason ("socket-ux unreachable" vs. "nothing synced from RDMO yet — run `regimo-core sync`"); `TheEditor` no longer falls back to a bundled crate; `TheDatabus` shows an offline hint instead of a demo message; `TheTransform` becomes a live view of the drawer-selected project.
3. **Empty-RDMO behaviour (engine, existing and confirmed):** with RDMO reachable but empty, `SyncEngine.run_once` forgets vanished projects, deletes their artifacts, replaces the (now empty) default graph and publishes `project.removed` events — covered by `core/tests/test_sync_engine.py::test_removed_project_forgets_artifact_and_announces`. RDMO *unreachable* ≠ RDMO *empty*: `list_projects()` raises → the sync round aborts, state is untouched (no wipe).
