# EDO Release v0.2.0 (2026-11-23)

The **observable bus** release: Kafka traffic becomes visible in the UI (CF1-012) and the UI drops all demo data in favour of real empty states (CF1-013).

## What ships

| Repository | Tag | Commit | Scope |
|---|---|---|---|
| [[EDO]] (umbrella) | `v0.2.0` | *(this commit)* | socket-ux databus REST bridge, cards, release note |
| `regimo-core` | `v0.2.0` | `0bf9e8e` | `sync.round` heartbeat on `edo.sync.v1`, CLI help fix |
| `regimo-infrastructure` | `v0.2.0` | `a190630` | trip/agnostic-trip verify replay-graph cleanup |
| `vue-frontend` | `v0.2.0` | `c60313f` | live databus tracker, pinnable Bus drawer, no-demo-data empty states, icon fix |

`components/socket-rdmo` and `schema/ontology` have no changes in this cycle — their versions and tags stay at `v0.1.0` (no tag issued).

## Highlights

- **Databus bridge (CF1-012):** socket-ux exposes `/api/v1/bus/*` (topics, messages, status, SSE) backed by per-topic ring buffers; core publishes a `sync.round` heartbeat on the new `edo.sync.v1` topic after every sync round, including idle ones.
- **Bus drawer + live tracker (CF1-012):** right-side pinnable drawer in the UI backfills all `edo.*` topics and follows them live over SSE; a last-sync chip shows sync liveness.
- **No-demo-data policy (CF1-013):** Weatherstation and internal-format fixtures removed; every view renders a faithful empty state when RDMO has no projects (editor overlays the NovaCrate error screen; drawer refetches on SSE reconnect).
- **Cleanup:** trip/agnostic-trip verify now `DROP SILENT` their replay named graphs, so no leftover Weatherstation data resurfaces in Fuseki `/projects`.
- **Root-cause icon fix:** the app loaded no Material Design font; Vuetify's bundled `mdi-svg` icon set is used now.

## Verification evidence (2026-11-23)

- **Tests:** socket-ux bridge 45 tests pass; core sync engine 34 tests pass.
- **Frontend:** `pnpm type-check` and `pnpm lint` green.
- **End-to-end:** bridge exercised through the Vite proxy (`/bus` → :8090) with live Kafka messages from the sync run; empty-RDMO behaviour verified (engine forgets + wipes when RDMO empty, aborts untouched when unreachable).
